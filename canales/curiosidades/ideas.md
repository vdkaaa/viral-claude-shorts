# Banco de ideas: Curiosidades del ser humano

Cómo se escribe cada guion: `formula.md` (en esta misma carpeta).

Estados: `idea` → `guion` → `audio` → `video` → `programado` → `publicado` (con fecha y enlace). `node core/canal.ts` los calcula solo a partir de los archivos de cada video.
